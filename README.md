# 璃瞳 · LumiIris Studio Desktop Releases

> 桌面端独立发行仓库（Windows / macOS），与移动端 `lumiiris-releases` 仓库严格隔离。

## 清单文件说明
- `desktop-version.json`: 桌面端最新版本清单（Windows `.exe` / macOS `.dmg`、天翼云盘访问码与 SHA-256 校验）
- `notices.json`: 桌面端公告消息清单
- `resources.json`: 云端扩展高光/素材包清单

## 下载安装
可前往天翼云盘分享目录下载最新版 `LumiIrisStudio-v1.0.7-win-x64.exe`（[天翼云盘链接](https://cloud.189.cn/web/share?code=NRfquinUjm6r)，提取码：`9tv6`；Windows 单文件独立运行版，内置 .NET、SkiaSharp 与官方桌面图标，首次从下载目录/微信/QQ打开会自动创建桌面快捷方式，免安装直接运行），或在桌面端 **设置与档案 → 电脑版独立更新中心** 点击 **检查新版本**。
