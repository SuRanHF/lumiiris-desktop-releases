# 璃瞳 · LumiIris Studio Desktop Releases

> 桌面端独立发行仓库（Windows / macOS），与移动端 `lumiiris-releases` 仓库严格隔离。

## 清单文件说明
- `desktop-version.json`: 桌面端最新版本清单（Windows `.exe` / macOS `.dmg` 与 SHA-256 校验）
- `notices.json`: 桌面端公告消息清单
- `resources.json`: 云端扩展高光/素材包清单

## 下载安装
请前往本仓库 [Releases 页面](https://github.com/SuRanHF/lumiiris-desktop-releases/releases/latest) 下载最新版 `LumiIrisStudio-v1.0.3-win-x64.exe`（Windows 单文件独立运行版，内置 .NET 与 SkiaSharp，免安装直接运行），或在桌面端 **设置与档案 → 电脑版独立更新中心** 点击 **检查新版本** 自动校验下载。
